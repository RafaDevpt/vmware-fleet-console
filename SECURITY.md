# Security Policy

## Supported versions

Only the latest release of VMware Fleet Console receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository
(<https://github.com/RafaDevpt/vmware-fleet-console/security/advisories/new>).

Include the version, the platform (Windows, Linux or macOS), the steps to
reproduce and the impact you expect. You will get an answer within 7 days;
fixes are released as a new patch version and credited in the CHANGELOG
unless you prefer otherwise.
